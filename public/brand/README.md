# Forge Logo Pack (Calendar Forge)

This directory contains ready-to-use logo assets for Forge.

## Files

- `forge-logo-primary.svg` — Main horizontal lockup (icon + FORGE)
- `forge-logo-primary-darkbg.svg` — Main lockup for dark backgrounds
- `forge-logo-primary-black.svg` — Monochrome black lockup
- `forge-logo-primary-white.svg` — Monochrome white lockup
- `forge-logo-icon.svg` — App icon / square standalone icon
- `forge-logo-icon-darkbg.svg` — Standalone icon for dark backgrounds
- `forge-logo-icon-black.svg` — Monochrome black icon
- `forge-logo-icon-white.svg` — Monochrome white icon
- `forge-favicon.svg` — Simplified favicon icon

## Recommended usage

- Header / marketing: `forge-logo-primary.svg`
- Sidebar avatar / app launcher: `forge-logo-icon.svg`
- Browser tab: `forge-favicon.svg`
- Dark sections: `*-darkbg.svg` or `*-white.svg`

## Size guidance

- Minimum icon size: 20px
- Minimum print size: 8mm
- Keep clear space around logo: at least 25% of icon width
